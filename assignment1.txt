Problem PC-1: Prime Number Checker
----------------------------------
Algorithm CheckPrime(N):
1. If N <= 1 then
      print "Not Prime"
      return
2. For i from 2 to sqrt(N) do:
      if N % i == 0 then
          print "Not Prime"
          return
3. Print "Prime"


Problem PC-2: Number Digit Reversal
-----------------------------------
Algorithm ReverseNumber(N):
1. reversedNum = 0
2. While N > 0 do:
      digit = N % 10
      reversedNum = (reversedNum * 10) + digit
      N = N / 10
3. Return reversedNum
